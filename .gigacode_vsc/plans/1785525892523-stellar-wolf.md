## 1. Расширение C API (`port_scanner.h`)

### 1.1 Расширение структуры PortResult

Добавить поля `version` и `banner` в существующую структуру:

```c
typedef struct {
    char* host;        // Имя хоста
    int port;          // Номер порта
    int is_open;       // 1 если открыт, 0 если закрыт
    int is_udp;        // 1 если UDP порт
    char* service;     // Название службы (например "SSH")
    char* version;     // Версия сервиса (например "OpenSSH 8.9p1") — может быть NULL
    char* banner;      // Баннер приложения — может быть NULL
    int ssl;           // 1 если соединение SSL/TLS
} PortResult;
```

Новые поля:
- `is_udp` — флаг UDP сканирования
- `version` — версия сервиса (результат version detection)
- `banner` — захваченный баннер (результат banner grabbing)
- `ssl` — флаг SSL/TLS соединения

## 2. SYN Scan (`port_scanner.cpp`)

### 2.1 Реализация

Добавить метод `isPortOpenSYN()` в `PortScanner`:

```cpp
bool isPortOpenSYN(const std::string& host, int port) {
    // 1. Получаем IP адреса хоста через getaddrinfo()
    // 2. Создаём raw socket (IPPROTO_TCP)
    // 3. Настраиваем socket с IP_HDRINCL
    // 4. Формируем TCP SYN пакет вручную:
    //    - TCP header (src port random, dst port, seq=0, SYN flag, window=1024)
    //    - TCP checksum calculation
    // 5. Отправляем через sendto()
    // 6. Ждём ответ с таймаутом:
    //    - RST+ACK -> порт закрыт
    //    - ACK -> порт открыт, отправляем RST для разрыва
    //    - ICMP error -> порт недоступен/filtered
    // 7. Освобождаем ресурсы
}
```

### 2.2 Особенности реализации

- **Privileges**: SYN scan требует root/CAP_NET_RAW. Реализовать graceful degradation — если raw sockets недоступны, автоматически переключиться на connect scan и вывести предупреждение.
- **macOS compatibility**: На macOS raw sockets работают иначе. Использовать `SO_CONNECT_TIME` опцию для определения открытости порта как fallback.
- **Checksum calculation**: Реализовать RFC 793 checksum для TCP header + pseudo header.

### 2.3 Переключение типов сканирования

Добавить член `ScanType scanType` в класс и модифицировать `isPortOpen()` для использования нужного метода в зависимости от типа.

## 3. Version Detection (`port_scanner.cpp`)

### 3.1 Алгоритм

После обнаружения открытого порта выполняем:

```cpp
std::string detectVersion(const std::string& host, int port) {
    // 1. Подключаемся к порту через socket
    // 2. Ждём автоматический баннер (если есть)
    // 3. Отправляем protocol-specific probe:
    
    switch (port) {
        case 21:   // FTP
            send(sock, "FEAT\r\n", 6, 0);
            read(sock, buf, sizeof(buf)); // RFC 2389
            break;
        case 22:   // SSH
            send(sock, "SSH-2.0-PortScanner\r\n", 21, 0);
            read(sock, buf, sizeof(buf)); // Ожидаем "SSH-x.x-Software"
            break;
        case 23:   // Telnet
            send(sock, "\xff\xf8\x22\xff\xf5\x1f\xff\xfd\x03\r\n", 9, 0); // IAC negotiation
            read(sock, buf, sizeof(buf));
            break;
        case 25:   // SMTP
            send(sock, "EHLO scanner\r\n", 14, 0);
            read(sock, buf, sizeof(buf));
            break;
        case 80:   // HTTP
            send(sock, "HEAD / HTTP/1.1\r\nHost: target\r\n\r\n", 37, 0);
            read(sock, buf, sizeof(buf)); // Server header
            break;
        case 443:  // HTTPS — TLS handshake
            send_tls_client_hello(sock);
            read(sock, buf, sizeof(buf)); // Server certificate
            parse_certificate(buf);
            break;
        case 3306: // MySQL
            send_mysql_handshake(sock);
            read(sock, buf, sizeof(buf));
            break;
        case 5432: // PostgreSQL
            send_pg_startup(sock);
            read(sock, buf, sizeof(buf));
            break;
        case 11211: // Memcached
            send(sock, "version\r\n", 9, 0);
            read(sock, buf, sizeof(buf));
            break;
        default:
            return "";
    }
    
    // 4. Парсим ответ и извлекаем версию
    // 5. Кэшируем результат
    
    return extracted_version;
}
```

### 3.2 Кэширование

Результаты version detection кэшируются по ключу `(host, port)` чтобы не запрашивать дважды при многократном сканировании.

## 4. Banner Grabbing (`port_scanner.cpp`)

### 4.1 Реализация

```cpp
std::string grabBanner(const std::string& host, int port) {
    // 1. Подключаемся к порту
    // 2. Если порт SSL/TLS (443, 993, 995, 465 и т.д.):
    //    - Выполняем TLS handshake
    //    - Извлекаем сертификат и параметры
    //    - Проверяем: self-signed, expired, weak cipher suites
    // 3. Иначе:
    //    - Ждём 500ms для автоматического баннера
    //    - Если нет баннера — отправляем пустой запрос (для HTTP) или timeout
    // 4. Возвращаем первую строку баннера или полный баннер (до 1024 байт)
}
```

### 4.2 SSL/TLS детекция

Для HTTPS портов (443, 8443, 993, 995, 465, 587):
- Отправляем TLS ClientHello
- Если получен handshake ответ — помечаем порт как SSL
- Извлекаем информацию из сертификата:
  - Subject CN
  - Issuer
  - Validity dates (expired?)
  - Key strength

### 4.3 Хранение

Результаты banner grabbing хранятся в `PortResult.banner` и выводятся при запросе результатов.

### 5.3 Экранирование строк в JSON

```cpp
std::string jsonEscape(const std::string& s) {
    std::string result;
    for (char c : s) {
        switch (c) {
            case '"': result += "\\\""; break;
            case '\\': result += "\\\\"; break;
            case '\n': result += "\\n"; break;
            case '\r': result += "\\r"; break;
            case '\t': result += "\\t"; break;
            default: result += c;
        }
    }
    return result;
}
```

## Риски и смягчение

1. **SYN scan требует root** — graceful fallback на connect scan с предупреждением
2. **macOS raw sockets** — использование `SO_CONNECT_TIME` fallback
3. **UDP сканирование медленное** — по умолчанию ограниченное количество портов, configurable timeout
4. **JSON без зависимостей** — простая сериализация достаточна для MVP, можно добавить nlohmann позже
5. **Android/iOS ABI compatibility** — C API остаётся стабильным, новые поля добавляются в конец структур
